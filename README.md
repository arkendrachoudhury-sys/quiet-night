# Quiet Night

A small, calm app for anxious nights. No ads, no tracking, nothing saved.

## What's inside
- **Breathe:** a slow breathing guide
- **Worries:** type what's on your mind and funny doodle friends react
- **Tonight:** five simple sleep tips

To install it
>>
Send quiet-night to your phone, or download it there. Open it and allow “Install unknown apps” for that app when asked.
If Play Protect warns that the app is unrecognised, that’s expected for a file not from the Play Store. Choose “Install anyway”.
